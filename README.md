# 金工手帖

ジュエリー・金工制作のための道具箱。地金相場の確認、体積からの重量計算、
鋳造工賃の見積比較、作業の記録ができます。

https://kotodama2231.github.io/kinko-techo/

ブラウザだけで動きます。データは各自の端末内に保存され、外部には送信されません。

## 相場について

金・プラチナ・銀・パラジウムの価格は LBMA（ロンドン貴金属市場協会）の公表建値を
ECB の日次為替で円/gに換算した参考値です。国内の店頭小売価格は業者マージンと税を
含むため、1割前後の差が出ます。設定タブの「上乗せ」で補正できます。

見積はいずれも概算です。実際の請求と差が出ることがあります。
